# Redrob Releases

Downloads for Redrob apps by McKinley Rice: installers and update files only. The source code is
private and is not here.

Each app's releases are tagged `<app>-v<version>` (for example `redrob-desktop-v0.1.0`). The
release `<app>-latest` holds the update feed that app reads.
